# SKY130 source-defined MOS voltage screen

This static, qualification-only library classifies source-relative VDS, VGS and VBS against the model-validity ranges stated in the retained SKY130 public documentation. It does not restrict simulations or establish absolute maximum ratings, rated operating limits, temperature limits, safe operating area, PCell geometry limits, reliability or a complete operating envelope. It does not promote a device status.

The reviewed source defines 17 model identities: 16 have 40 catalog bindings in the current `b26f7f28e659ddc1` package, while the ESD PFET is source-only and has no asserted catalog binding. Four ambiguous ESD identities are outside this finite contract. The isolated high-voltage device's fifth substrate terminal has no independent bound established here. The two 16 V drain allowances apply only at exactly zero VGS and remain subject to separate source-required SOA.

Historical bias sweeps cover discrete points in 11 models under package revision `1901822ae8f81ae1` at three temperatures and five corners. Axis spans and sample counts identify that earlier evidence; they do not claim that a continuous interval or a point under the current package was simulated. TNOM is a model parameter, not a temperature operating range.

Public documentation is SkyWater PDK, revision `7198cf647113f56041e02abf3eb623692820c5e1`, Apache-2.0; see retained `sources/LICENSE`, `sources/NOTICE.txt`, `sources/device-details.rst`, and `sources/hv.rst`. Source paths, locations and SHA-256 values are recorded in the retained locks and each model-validity fact. Current package model-file hashes authenticate packaged bytes; they do not claim every packaged file is byte-identical to an upstream public tree.

The library and both test modules are integrated. The immutable gap table preserves its original candidate label; current integration evidence is recorded in [the combined source check](../../validation/chunk7-final-integration-2026-10-28.json). Instantiate `QualificationVoltageContract` only in an explicit qualification/reporting workflow, and call `screen` with an exact model name or exact catalog key plus source-relative voltages and temperature. `model_inventory` enumerates sourced relations, qualifiers, catalog bindings and unresolved axes. No default simulation path or installed acceptance is changed. Run both included test modules with the repository on Python's import path. Source package/model files and every source contract must pass the pinned identity checks before screening.
