# Public SKY130 LI contract sources

These two unmodified documentation files come from google/skywater-pdk revision
`7198cf647113f56041e02abf3eb623692820c5e1`. `SOURCE.json` records exact upstream
paths, URLs and SHA-256 hashes. The original Apache-2.0 license is retained in
`LICENSE`; the project license does not replace it. No model or rule is altered.

The generic-device prose is already retained, with the same revision and license,
in `../sky130-mos-bias-sources-v1/`. The LI rule-table bytes match the existing
`../sky130-rule-inventory.json` hash. The sheet-resistance table supplies
specification values without a complete measurement procedure or operating
envelope. See `../sky130-li-contract-v1.json` for the separate interpretations.
