GF180 MOS electrical specification sources
==========================================

Unmodified excerpts and tables from google/gf180mcu-pdk at revision

GlobalFoundries PDK Authors. These sources retain Apache-2.0; see LICENSE.

`sources.json` records origin, exact revision and SHA-256 for each source.
The selected scope is the 3.3 V MOS electrical table, reference dimensions,
bias and temperature definitions, and fixed-corner definitions. Other linked
sections and images are not part of this source subset or acceptance claim.
Numeric differences must remain visible; no target is fitted to a simulation.
