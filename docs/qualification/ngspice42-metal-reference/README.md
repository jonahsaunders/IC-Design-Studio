# Selected ngspice 42 reference sources

These seven unchanged upstream files document the primitive resistor equations
used by the selected metal-resistor qualification contract. They are reference
material, not a replacement simulator build or a claim of reproducible binaries.

The source archive is Ubuntu's `ngspice_42+ds.orig.tar.gz`, SHA256
`cae144ba1d28a56a867e09b9d7665fdf71182e568300e379803786fb0c3165b7`, from
<https://archive.ubuntu.com/ubuntu/pool/universe/n/ngspice/>. Exact original member
names and per-file hashes remain in `sky130-metal-resistors-linked-v1.json`.

The C and header files retain their original University of California copyright
notices and use the Modified BSD terms reproduced in upstream `COPYING`.
`COPYING` itself states [CC-BY-SA 4.0](https://creativecommons.org/licenses/by-sa/4.0/)
for that licensing document, attributed to the ngspice team. It is retained
verbatim, including its complete license notices;
it has not been relicensed under this project's license. The document also
describes other upstream components that are not included in this small bundle.
