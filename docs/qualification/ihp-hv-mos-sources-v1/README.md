# IHP high-voltage MOS source definitions

These byte-identical public IHP sources retain their Apache-2.0 license and
copyright notices. The project remains GPL-3.0; the upstream files keep their
own license. SOURCE.json records repository, revision, Git blob and SHA-256.

The PCells and technology parameters define minimum widths/lengths, implicit
N+ diffusion, thick oxide and well enclosures for standard 3.3 V MOS. They are
retained as qualification references, not executed or relabeled as project code.
The application's bounded layout recipe and required regression evidence are
separate. No private PDK material is included.
