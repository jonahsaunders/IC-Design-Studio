# Pinned KLayout wrapper sources

Six original, unchanged source files retain their GlobalFoundries/IHP copyright
and Apache-2.0 notices. The complete license is `Apache-2.0.txt`. Exact upstream
repositories, revisions, paths, Git blob identities and byte hashes appear in
`source-lock.json`; they match the November 8 historical disposition ledger.

These files support only a bounded, nonexecuting declaration readback. Includes
are literal dependencies, not replayed rules. The two IHP logging-only files and
the GF180 license-only file contain no device rule implementation. The GF180
LVS macro declares options and assignments without choosing or executing them.
No device, physical checker, operating envelope or installed result is qualified.
The historical complete inventory and its 107 gaps remain unchanged until a
fresh complete authenticated audit is run.
