# Exact GF180 Xschem configuration facts

This fixture contains source identities and declaration facts only, not copied
upstream configuration prose or code. The source lock names exact repositories,
revisions, paths, original Git identities and SHA-256 hashes, plus the inspected
repository-level Apache-2.0 licenses. These headerless Xschem-derived sources
are not redistributed based merely on a wrapper license.

Three exact GF180 configuration views yield 110 unevaluated facts. Original
variable assignments, conditional branches and dependency expressions remain
separate; no path, simulator, model, callback or runtime behavior is resolved.
The stray historical `XSCHEM_LIBRARY_PATH` command reference is retained, not
silently repaired or interpreted as a variable assignment.

The IHP configuration remains excluded because the existing generic Tcl reader
does not enumerate its Tk button callback. Both GF/IHP menu sources remain
unsupported. No source gap count changes before integration and a new complete
authenticated audit. Original source bytes can be recovered into the private
cache by `scripts/recover_source_disposition_cache.py`; the optional real-source
regression uses `ICSTUDIO_SOURCE_CACHE` to read and authenticate that cache.
