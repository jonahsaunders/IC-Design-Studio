# Original 0.13 handoff notes

This directory preserves the original continuation notes, roadmap and selected
machine-readable verification summaries from the supplied 0.13.0 handoff.
Results describe the original release and environment; they were not rerun or
rewritten during repository preparation. Original absolute paths and historical
filenames in these records identify the old build environment.

Read [HANDOFF.md](HANDOFF.md), [NEXT.md](NEXT.md) and
[verification/RELEASE-RESULTS.json](verification/RELEASE-RESULTS.json).
The original handoff contains the referenced update guide, screenshots, logs,
patches and full historical evidence. The current update guide is also available
at [../UPDATE_0.13.md](../UPDATE_0.13.md).

The GitHub source tree intentionally omits the handoff's binary bundles,
`tool-inputs/`, archived evidence and historical patch bundles. Keep the original
handoff for complete recovery. See [the upload guide](../../UPLOAD_TO_GITHUB.md)
for the companion files to attach to a GitHub Release.

Repository preparation preserves every application module, example, test and
license from the original source ZIP. Documentation, ignore/line-ending rules
and GitHub workflow setup are the repository preparation changes. No application
version bump or application behavior change was made.
