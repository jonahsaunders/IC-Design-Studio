# SKY130 imported MiM conditioning qualification

This candidate qualifies a finite, explicitly selected source-derived AC replay of the original larger-common-mode stimulus. It is a separate qualification adapter, not a change to the application simulator or the SKY130 public model. The original unmodified v1 execution remains a recorded numerical failure. The earlier v2 result remains a separate acceptance of its smaller conditioned stimulus; it did not repair the original v1 execution.

For the two selected MiM model definitions the adapter replaces each resistor stamp with a current-sensing voltage source and a current-controlled voltage source imposing the same source-defined resistance. The selected DC bias is zero, TEMP and TNOM are both 27 °C, multiplicity is one and statistical switches are zero. It retains each complete four-terminal application, historical reference and native extraction network, four signed source currents and the original stimulus, frequencies and numerical criteria. The transformation is not a general replacement for resistor models: noise, transient, other temperatures, multipliers, geometries and statistical cases are outside this contract.

The public fixture contains the 40 fixed deck templates and their reviewed staged sources. Its compressed bundle is 4,537,429 bytes. The fixture is self-contained; the builder requires no retained or private archive. Its manifest differs from the previously tested internal fixture only by omitting `assets/shared-models/source-identity.json`, an unreferenced staging metadata file that included a historical local path. All 40 decks and all 346 remaining source files are byte-identical; [the difference record](qualification/sky130-mim-conditioning-v1/fixture-provenance.json) records both manifest identities and the omitted file's identity. No electrical source was sanitized.

The fixed source bundle SHA-256 is `c3f66bd57fdfcb95744061ae717142409ded07aa7c43cb4447a25feddd41c6c0`, and the unpacked fixture manifest SHA-256 is `1d433b5a3317b36bbcfaa8cf9037146a74256c76e5f40ba4f2aac35463631eed`. Public SKY130 source material is Apache-2.0, and the repository's derivative adapter material is GPL-3.0-or-later; the retained notices and both licenses accompany the bundle. The package source identity is the already-reviewed `b26f7f28e659ddc1` manifest `840f7af802b07346650c50a5967e532a4cb1716623cf0c9d6fd6c58eaf35fcbe`; packaged transformations are not represented as upstream-identical public files.

A fresh complete public-fixture replay is independently audited on Windows ngspice 46 and Linux ngspice 42. Each host covers 40 runs, eight frequencies, six complete paths, and 1,920 network-frequency samples, with 60 detected cross/missing/width faults. The maximum normalized current error was approximately `4.02e-9` of the original tolerance bound on each host. The independent reader validates input reconstruction, runtime identity, signed terminal voltages and currents, KCL, Y/R/C and isolation. The [validation record](validation/sky130-mim-conditioning-2026-10-28.json) records exact evidence identities and boundaries.

To reproduce, first use `scripts/qualification/sky130_mim_conditioning/build_fixture.py` with explicit bundle, bundle SHA, fixture manifest SHA and a new output directory. Use `build_runtime_lock.py` to propose an engine, initializer and library identity, then review and pin the resulting runtime-lock SHA separately. On Windows the builder records the packaged OpenMP companion DLL when present; use `--runtime-file` for other applicable companions. On Linux it records the dynamic-library closure. Supply the fixture, its SHA, the reviewed runtime lock and SHA, the compatible engine, an empty case output path, and the selected fixed case key to `replay.py`. Use `audit_pilot.py` with the source contract and pinned replay-source SHA for an independent single-case readback. A full 40-case qualification must execute every listed case and retain the source/engine manifests, independent audits, original decks, raw files, logs and negative controls. The scripts reject unsupported deck changes; they do not intercept or limit ordinary simulations. The existing source-release and handoff workflow includes the exact fixture bundle and authenticates its Git blob. Focused tests exercise actual Source and GitHub ZIPs and reject missing or changed fixture bytes; no archive policy change is required. The full portable source/evidence archive is retained separately in the qualification evidence store, not in the repository.

This closes only the selected source-derived finite replay class. It does not change existing device-family status, installed acceptance, complete operating limits, physical classes, noise/transient qualification or foundry signoff.
