# IHP `cap_cmim` four-terminal spacing experiment

This bounded source experiment places two separate imported 7 × 7 µm capacitors, each with its original 25 Vmim cuts. The four physical terminals are C1/C2 and C3/C4; no plates are intentionally shared. It tests the selected rectangular construction, not arbitrary capacitors, parasitics, operating limits, installed applications or full-family qualification. The [execution record](validation/ihp-cmim-isolated-spacing-2026-11-03.json) binds the native outputs and independent raw reviews.

Each original Metal5 plate surrounds its MIM by 0.60 µm. For these aligned rectangles, the Metal5 separation is therefore the MIM separation minus 1.20 µm. The two TopMetal1 plates are inset 0.20 µm from the respective MIM edges, so their separation is the MIM separation plus 0.40 µm. The source tables specify MIM.b at 0.60 µm, Metal5 M5.e at 0.24 µm for the applicable wide, long parallel edges, and TopMetal1 TM1.b at 1.64 µm. Those constraints explain why the 0.60 µm shared-electrode boundary does not directly provide four separate electrodes in this construction.

The original, unmodified public main and maximal decks reported zero findings at all six selected placements, including the two below-limit 0.22 µm Metal5 gaps. This was a real false pass against the source M5.e condition; its predeclared negative assertions and failed producer report remain retained. The main-deck log shows M5.e executed. A separate native operation probe reproduces the missed result and isolates shielding of the wide-metal subset as the observed behavior. A six-point diagnostic also recorded M5.b at 0.20 µm and no native M5.e at 0.21, 0.22 or 0.23 µm. These observations do not approve those clearances.

The corrected source overlay keeps both original public decks unchanged and adds a separately identified, source-bound transparent wide-metal spacing check. At each rotation the raw outcomes were:

| MIM gap | Metal5 gap | Original main / maximal | Supplemental M5.e | Strict LVS |
| --- | --- | --- | --- | --- |
| 1.42 µm | 0.22 µm | 0 / 0 | 2 edge-pair markers | Pass |
| 1.44 µm | 0.24 µm | 0 / 0 | 0 | Pass |
| 1.46 µm | 0.26 µm | 0 / 0 | 0 | Pass |

The two supplemental markers at 0.22 µm are reverse edge-pair representations of the same spacing interaction, not two independent gaps. All six corrected runs completed unfiltered native extraction and strict LVS. A predeclared physical `C` reference supplies two devices; independent written GDS/OASIS and native-netlist readback checks the 50 original contacts, separate plate masks, all four physical labels and exactly two `cap_cmim` records with distinct ordered C1/C2 and C3/C4 nets. Each extracted device retains W/L 7 µm, area 49 µm², perimeter 28 µm and multiplicity one.

Five controls were retained on both the original and corrected routes. Wrong reference width and a physical electrode-label swap each reached native LVS and failed. Removing one contact array, joining the two top plates, and shorting a top plate to its bottom plate each completed raw extraction but triggered the application's changed-port guard; LVS was not run for those three cases. The contact removal also produced MIM.h, and the cross-plate short produced retained TM1.b and TV1.c/d findings. An independent reader examined the actual fault nets and did not treat an execution error as detection.

Separately, the legal 1.44 µm layouts at both rotations were paired with two freshly created ordinary catalog capacitors. Their actual saved simulation references retained two `X` statements and `mm_ok=1`; the application independently projected each into its physical `C` comparison form. All three geometry checks and strict LVS passed with the four separate nets. A deliberate 7.2 µm width on the second catalog instance produced native A/P property errors and a top-level pin mismatch; strict LVS failed. The first catalog fixture placed both schematic symbols at the same location and failed project validation because the labels conflicted; that setup failure is also retained. An independent addendum checked the saved instances, unchanged simulation statements, source-bound projections, written masks and native results, and rejected four corruption controls. This small catalog selection does not extend the five physical fault results to additional catalog cases.

The supplement applies the pinned metal-rule morphology and thresholds with transparent separation as a distinct, versioned result. Its selected geometry and source-level controls do not establish complete coverage of all metal shapes, a manufacturing signoff or other process rules. The original failed negative, six-point diagnostic, corrected source overlay, independent review and source/runtime receipts are retained separately and read back as described in the execution record. Reproduction uses the archived external drivers, recorded source and runtime plus fresh output directories; no repository CLI for this selection exists.
