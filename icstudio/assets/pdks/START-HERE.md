# Included simulation PDKs

In IC Design Studio, choose **Tools → Set up an open PDK → Use included PDKs**. Then select a revision and choose **New project with this PDK**. These packages install offline.

- GF180MCU D adapter: 64 placeable / 68 indexed primitive symbols, transistor/bipolar/passive models, and layer display map.
- SKY130A adapter: 71 placeable / 74 indexed symbols, complete primitive corner model closure, and layer display map.

These are simulation subsets, not full foundry PDK installations. No standard-cell libraries, Magic/Netgen decks or IHP OSDI binaries are included. Every asset is checksummed; upstream revisions and licenses are retained. Gallery examples configure their models automatically.
