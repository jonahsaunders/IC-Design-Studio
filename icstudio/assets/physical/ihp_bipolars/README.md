# Public IHP bipolar reference geometry

Unmodified IHP SG13G2 public LVS test layout and matching CDL, pinned in
SOURCE.json. Original Apache-2.0 headers and LICENSE are retained. The local
qualification runner selects named cells and explicitly adds substrate metal
and contacts inside the existing P+ guard. No source fixture is overwritten.
These files are reference inputs, not qualified standalone tapeout macros.
